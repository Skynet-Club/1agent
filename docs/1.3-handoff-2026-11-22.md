## What landed

- Route/risk follows `InteractionMode` and permissions, not wording; follow-up
  sentences no longer die as `NoRoute`.
- Durable conversation sessions, continuation without capability preflight,
  TUI `--continue`, session-end rating.
- Already-done gate, verification-only mode, versioned new-version paths.
- TUI tool surface 38 → 16 → 10 → **7** (5 core + `describe_self`/
  `request_tools`); edit/search/preview/browser/clarify are request-only.
- Instruction deltas: core + on-demand artifacts, capability, skills, page,
  prompt-library, memory, follow-up and Answer/Ask blocks.
- Compact acceptance schema (shape-only; detailed rules in the prompt delta).
- Reasoning part: `reasoning_content` streamed into one TUI Thinking row and
  stored as `SessionEntry::Reasoning`; never replayed into model context.
- System prompt compaction: first Act system message 3,688 → **3,116** tokens.
- Session compaction: deterministic extractive summary above 20 entries/24k
  chars, keeps the last 10 verbatim, projection uses `first_kept_index`.
- Steering: `/steer <text>` during a run is injected at the next model step;
  plain Enter remains the follow-up queue; leftovers are requeued.
