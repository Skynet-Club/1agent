## Residual risks

1. MCP CIMD/Tasks/MRTR are gated/fail-closed; local real stdio and modern HTTP servers are tested, but no remote hosted server or OAuth authorization-server evidence exists, and in-task input is not implemented.
2. Browser action approval is a human-consent/audit control, not a hard boundary against a model that also has terminal-write permission. Run W2 without terminal write access.
3. bwrap/Landlock/seccomp browser wrapper is not implemented; Chrome's own sandbox is preserved. Secret text-field screenshot masking is best-effort (`-webkit-text-security`), not a page-JS boundary.
4. Skill blind comparator and held-out split are implemented as deterministic library primitives; they are not yet a mandatory activation gate. Skill scripts are never auto-executed; `skill run-script` is explicit and bwrap-sandboxed.
5. Scheduler has skip-if-late + deterministic jitter + 100-slot and 100-process-crash matrices; bounded/all catch-up variants and destination idempotency are not implemented.
6. W1 is green (`docs/evidence/0.98-w1/`). W2/W3 real workflows and the consolidated adaptive red-team report are blocked on owner systems/credentials.
7. 1h M1 is green: **rerun3 239/240 = 99.58%**, completed replay 100%, 0 crashes (`docs/evidence/m1-1h-2026-11-15-rerun3/`). The remaining 8h soak still needs an owner-approved run window. The M1 binary predates the TUI interaction changes; `benchmark-run` does not use the TUI.
8. Packaging/release gates and owner publication approval are pending; the tree is uncommitted.
9. Disk is tight (~40 GB free); `target/debug/incremental` must be cleaned periodically.
10. The interactive setup wizard assumes a UTF-8 terminal (Unicode block/box
    glyphs); `NO_COLOR` only disables color. Five-user timing remains pending.
