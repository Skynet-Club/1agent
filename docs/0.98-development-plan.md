## 0. 一页结论

### 0.1 0.98 的定位

0.97 证明的是“可审计的 Agent Runtime”；0.98 要证明的是：

> **Agent 能在真实世界里执行，但每一步都可授权、可接管、可回滚、可验收。**

主题：**Real World**。  
方式：**7 个垂直切片，三车道并行，W0 契约周 + 11 个交付周（参考节奏），每周一个集成门。**  
原则：**进度优先、门禁优先；时间只用于规划，不用于降低质量门槛。**

### 0.2 七个切片

1. Onboarding + CLI IA（第一切片）
2. Computer-use / 浏览器写沙箱
3. MCP 连接器
4. 技能闭环
5. Daemon / trigger / routine / watchdog 产品化
6. 三个真实工作流 + 红队
7. 文档与发布

### 0.3 五条硬不变量

无论进度多紧，这五条不妥协：

1. **高风险动作默认拒绝**；不可逆动作必须单步绑定、人工确认。
2. **密钥不进模型上下文、不进 journal、不进 stdout**；模型可见输入必须能从 journal 重建。
3. **不自动 resume、不自动 kill**；KILL 开关始终有效，人工接管始终可用。
4. **MCP server annotations 与 skill `allowed-tools` 不能提权**；本地策略永远优先。
5. **安全门未过不发布**；不把未验证、未达标写成通过。

## 2. 0.98 产品定义与验收边界

### 2.1 用户结果

1. 新用户 **≤5 分钟**完成第一个成功任务，无需手改文件。
2. Agent 能操作真实浏览器，但 **不可逆动作必须人工确认**，人可随时接管。
3. Agent 能连接真实 MCP 工具，支持 OAuth，工具定义变化会 **fail closed**。
4. Agent 能从一次运行捕获技能，经过 held-out 评测、canary、回滚后才激活。
5. Agent 能按计划跨重启运行 routine，**不重复副作用**，不自动 resume/kill。
6. 三个真实工作流有 journal、replay、成本、人工干预和红队证据。

### 2.2 非目标（0.98 明确不做）

- 不做 macOS/Windows 发布；
- 不做技能市场/远程签名；
- 不做自动更新；
- 不做第三方认证或“已审计”宣称；
- 不宣称通用 prompt-injection 免疫；
- 不做无人值守的高风险自治；
- 不做自动 resume/restart；
- 不把“功能写完”当成“验收通过”。

### 2.3 安全与审计不变量

1. **Rule of Two**：一个浏览器 session 最多同时满足“处理不可信输入 / 访问敏感数据 / 改变状态或对外通信”中的两项；三项全占时必须人工在环或拆分 session。
2. **动作绑定**：不可逆动作的批准绑定到 ground-truth 动作描述符 + nonce + 过期时间；模型生成的确认文本不是授权。
3. **密钥最小暴露**：模型只看到 `secret://` 引用；运行时在执行点解析；不进入 prompt/journal/截图。
4. **审计可重建**：每个动作有 descriptor、policy decision、approval、result、evidence；工具调用与结果成对。
5. **失败关闭**：权限、schema、hash、签名、审批任一不确定 → 拒绝，不“猜”。

### 3.2 Onboarding + CLI IA

**设计**

- `setup` 是编排层：`runtime_home::init` → provider → credentials → model → permissions → workspace → smoke → doctor。
- 状态机持久化到 `$ONEAGENT_HOME/setup.json`（0600，原子写）；`--check` 只读；`--resume` 断点续跑；`--force` 显式覆盖。
- 非 TTY 无 flags → exit 2，`error:` + `next:`，绝不 hang。
- 密钥：masked prompt 或 `--api-key-stdin`；禁止 `--api-key <value>` 新用法；0600 + `O_NOFOLLOW` + 拒绝 symlink。
- 模型探测：`/v1/models`；`base_url` 已含 `/v1` 用 `<base>/models`，否则 `<base>/v1/models`；Ollama 回退 `/api/tags`；5s 超时、禁重定向、HTTPS/loopback。
- 30s smoke：最小请求；失败给 `next:`；`--skip-smoke` 记录原因。

**命令 IA**

公开 13 个：`setup`、`status`、`tui`、`run`、`doctor`、`model`、`permissions`、`audit`、`replay`、`skills`、`schedule`、`serve`、`uninstall`。

其余按 8 组进 `help advanced`：`provider / memory / trust / ops / master / evolution / protocol / eval`。`help --all` 全量。旧命令不删除；`skill` 是 `skills` 别名；`init` 留 advanced。

**输出契约**

- 成功 JSON：`{"schema":"1agent.cli/v1","ok":true,...}`。
- 失败 JSON：`{"ok":false,"error":{"code","message","next","details"}}`。
- 人类输出：`error: ...` + `next: ...`；stdout 只放结果，日志走 stderr。
- 退出码：0 成功；1 运行失败；2 用法错误；3 策略/审批拒绝（新增，需 ADR 确认）。
- `NO_COLOR` / `--plain` / 非 TTY 自动去色。

**权限预设**

| 预设 | 写 | 网络 | 终端 | 审批 | 不可逆 |
|---|---|---|---|---|---|
| `read-only` | 否 | 默认否 | 否 | n/a | n/a |
| `safe` | 工作区内 | 默认否；开启需审批 | 需审批 | 高风险/网络/执行 | **总是确认** |
| `full-local` | 工作区 + 显式 root | 是 | 是 | 常规不审批 | **仍确认**；KILL 始终有效 |

`permissions explain` 打印实际映射；预设不是新授权层。

### 3.3 Computer-use / 浏览器写沙箱

**架构**

```text
task -> ephemeral profile -> egress proxy -> Chrome for Testing
     -> CDP (Page/Network/Runtime/Fetch/Input) -> AX tree + screenshot
     -> action descriptor -> CuaPlan::authorize -> action card -> execute -> journal
     -> optional human takeover -> cleanup
```

**关键决定**

1. **Chrome for Testing**，版本固定；Chrome 136+ 的 remote debugging 必须配独立 `--user-data-dir`。
2. 每任务一个 profile：`$ONEAGENT_HOME/browser/profiles/<task-id>/`；默认任务后删除；持久 profile 显式 opt-in；禁止用户日常 profile、扩展、密码管理器、同步。
3. CDP：`chromiumoxide` 0.9 包在 `BrowserDriver` trait 后；安全域用 raw CDP；固定协议版本 + protocol-drift canary。
4. **出口代理**：本地 CONNECT；allowlist；resolve→validate→pin；拒绝非 global IP、169.254.169.254、metadata、CGNAT、IPv4-mapped、NAT64；每个 redirect 重校验；下载域名限制；代理 token 只在本机。
5. **动作分级**：`read / navigate / input / submit / download / upload / auth / payment / delete / irreversible`。不可逆 default-deny；动作卡包含动作 id、origin、元素语义、数据 diff、后果、风险、nonce、过期时间；带外渲染；执行时重新绑定。
6. **凭据 broker**：`secret://<provider>/<label>`；origin 绑定；一次性 consent；不进入 prompt/journal；截图遮罩；审计只记 id + origin。
7. **人工接管**：headed Chrome + 控制租约；agent 暂停、人操作、显式 resume；headless screencast + 本地控制面板为 stretch。
8. **录屏**：CDP `Page.startScreencast` 帧 + 动作 JSONL；可选 ffmpeg WebM；保留期可配置。
9. **进程沙箱**：保留 Chrome 自带 sandbox；**禁止 `--no-sandbox`**；高风险任务可选 bwrap + Landlock + seccomp；用户命名空间不可用时降级并报告。
10. **防御定位**：架构防御，不宣称模型免疫；页面内容带 provenance、不作为指令；动作前校验；必要处 spotlighting；红队用自适应攻击。

### 3.4 MCP 连接器

**协议**

- **dual-era**：modern 2026-07-28（`server/discover`、`_meta`、`Mcp-Method`/`Mcp-Name`、MRTR、Tasks extension）+ legacy 2025-11-25/2025-06-18（`initialize` + session）。
- era 探测后缓存；不强制升级现有 server；modern header/body 必须一致，客户端也校验回应。
- 传输：stdio + Streamable HTTP；不新增 legacy HTTP+SSE。

**授权**

- OAuth 2.1 authorization code + PKCE S256；RFC 8707 `resource`；RFC 9728 protected-resource metadata；RFC 9207 `iss`；CIMD 优先；DCR 不启用。
- token 只存 0600/内存；HTTPS only；短 TTL；refresh 去重；**禁止 token passthrough**；audience/issuer 强校验。
- Tasks/MRTR：`input_required` 渲染为 clarify/审批；Tasks TTL 上限、可取消、按 `task_id` 审计；task id 视为不可信 handle；URL elicitation 只展示 origin，不自动批准。

**工具与审计**

- 首次连接记录完整工具定义 canonical SHA-256（name/description/input/output schema/annotations）；每次 `tools/list` 重校验；变化 fail closed，要求人工重新批准。
- 所有 MCP 工具默认按写能力处理；annotations 只是 hint；风险分级 + 每工具 consent。
- 本地 JSON Schema 2020-12 校验；请求/结果大小上限；超时；结果带 provenance；审计记录 server/tool/version/definition hash/decision。
- 对象级授权：handle + 当前授权上下文 + scope；跨用户/跨租户/撤销后重放测试。

### 3.5 技能闭环

**格式与生命周期**

- agentskills.io `SKILL.md` + `scripts/` / `references/` / `assets/`；本地 validator 检查 frontmatter、路径、大小、脚本、外部引用。
- 状态：`captured → draft → scanned → evaluated → approved → canary → active → rolled_back/retired`；draft 永远 inert。

**评测与 Canary**

- 固定测试集 + held-out；pass@1/pass@3、token/time、工具调用；盲比较（skill vs no-skill、v1 vs v2）；多 run 干净上下文；记录方差；Wilson/McNemar。
- 负迁移门：held-out 严格提升且无回归才激活；capability uplift 与 encoded preference 分开评估。
- Canary：持久状态；按 workflow/schedule/用户切片；先 shadow（effects suppressed），再 1%/10%/50%/100%；预设回滚阈值；自动回滚；100% 前人工批准。
- 移除 `skill activate` 的 eval 绕过；`--force` 必须审计且默认拒绝。

**供应链**

- Ed25519 签名 + 全文件 SHA-256 + lockfile；禁止可变外部引用；脚本在 bwrap/Landlock/seccomp 沙箱运行；不可用时 fail closed 或明确警告；`allowed-tools` 不能提权。
- 扫描只是信号，不是保证；发布时披露残余风险。

### 3.6 Daemon / trigger / routine / watchdog

**调度**

- 新增 `ScheduleRunLedger`：append-only JSONL + fsync；key = `(schedule_id, scheduled_at)`；状态 `claimed/running/completed/failed/interrupted`；pid lock 单写者。
- claim 先于 spawn 写入并 fsync；崩溃在 claim 后、spawn 前 → `interrupted`，默认不自动重跑（at-most-once），由 missed-run policy/人工决定。
- IANA timezone、DST、显式 missed-run policy、hash jitter、overlap guard、catch-up 队列、max runtime、budget。
- `IdempotencyStore` 接到工具/job side effect；key 从 schedule + step + args 派生，不从模型输出派生。

**守护**

- `1agent daemon install-unit --print|--write` 生成 systemd user unit；加固字段；不自动 `enable-linger`；内置 daemon 仍是状态源。
- `sd_notify` `READY=1` / `WATCHDOG=1`（≤ WatchdogSec/2）；健康检查：last tick、queue lag、provider error、disk。
- watchdog 默认只建议；`--execute pause` 显式 opt-in；**不自动 resume/kill/restart**。
- 告警 webhook/桌面通知；去重、限流、receipt；升级阶梯保留人工确认。

## 7. 风险登记

| 风险 | 影响 | 缓解 |
|---|---|---|
| 范围过大/进度压力 | 延期/质量下降 | 三车道 + 门禁优先；延期不降门槛 |
| Chrome 136+ 调试限制 | 浏览器不可用 | 固定 CfT；独立 user-data-dir；doctor 检测 |
| chromiumoxide 协议漂移/编译成本 | 构建慢/诡异错误 | 固定版本；raw CDP escape；protocol canary；监控 `df -h /` |
| rmcp beta/`LATEST` 滞后 | modern MCP 不可用 | dual-era 自有实现；夹具；不强制升级 |
| 提示注入无法根治 | 红队失败/事故 | 架构防御、默认拒绝、人工接管、诚实披露 |
| 浏览器凭据被页面 JS 读取 | 密钥暴露 | 仅可信 origin；一次性 consent；遮罩；不把 secret 给模型 |
| 技能供应链 | 恶意技能执行 | 签名/hash/lockfile/沙箱/人工激活 |

## Appendix B：研究依据（2026-11）

### B.1 2026 年改变了什么

- **MCP 进入 stateless 时代**：2026-07-28 移除 `initialize`/session，改为 `_meta` 自描述 + `server/discover` + MRTR + Tasks extension；legacy 仍可 dual-era。影响：0.98 必须做 dual-era，而不是只升版本。
- **浏览器 agent 进入 GA**：Claude in Chrome 2026-08 GA，三层防御（训练、probe、action verification）；公开 eval 在强攻击下 ASR 0–0.3%。影响：动作前校验 + 默认拒绝是产品级要求，不是加分项。
- **动作卡从论文走向工程**：Verifiable Action Card 在 24 场景把 ASR 从 68–100% 降到 0%，合法完成 78%，误拦 0%。影响：不可逆动作必须带外渲染、绑定 ground-truth descriptor。
- **Agent Skills 成为开放标准**：agentskills.io；2026-10 捐给 AAIF/Linux Foundation；70+ 平台、百万级技能。影响：0.98 用开放格式，但必须补签名/hash/lockfile/沙箱。
- **技能供应链成为真实攻击面**：OWASP Agentic Skills Top 10 v1.0；ClawHavoc 等事件；扫描器可绕过。影响：静态扫描不够，必须签名 + hash + 沙箱 + 人工激活。
- **Codex/Claude Code 把权限做成 product surface**：`:read-only/:workspace/:danger-full-access` profiles、6 种 permission modes、network allowlist、granular approvals。影响：0.98 的三预设必须有清晰语义与 explain。
- **durable execution 的共识**：run identity = `(schedule_id, scheduled_at)`、显式 missed-run policy、hash jitter、idempotency key、effectively-once。影响：0.98 用现有 JSONL + ledger，不引外部编排。
- **发布供应链基线**：cargo-dist 0.32、cargo-auditable、CycloneDX、GitHub attestations、Sigstore。影响：0.98 不迁 cargo-dist，但补齐 attestation/SBOM/审计。
