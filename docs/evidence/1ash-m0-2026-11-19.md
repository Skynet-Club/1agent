# 1ASH M0 — schema contract (2026-11-19)

Scope: schema and example contract only. No 1ASH runner, task suite or report
generation exists yet.

## Delivered

- `schemas/1ash/task.schema.json` — `1ash.task/v1`: environment, agent
  contract, budget, weighted success modules, safety gates, oracle, no-op
  baseline, two reviewers and provenance.
- `schemas/1ash/run.schema.json` — `1ash.run/v1`: task-set digest, subject
  (agent/harness/model snapshot/seed/tools/permissions), runner, judge, output.
- `schemas/1ash/trace.schema.json` — `1ash.trace/v1`: one canonical JSONL event
  with span/parent IDs and a closed event-type enum.
- `schemas/1ash/report.schema.json` — `1ash.report/v1`: metrics,
  pass@1/pass@k/pass^k, cost, p95 latency, safety ASR, confidence intervals,
  failure classes, findings, limitations, ABC checklist, runs, signatures and
  hash-chain tip.
- Examples for all four; `scripts/check-1ash-schemas.py` validates them with
  Python `jsonschema`; `tests/1ash_schema.rs` is the hermetic structural gate.

## Limits

- These are draft schemas, not a frozen external standard.
- ABC checklist mapping is represented as an object; individual checklist item
  mapping is still pending.
- No Inspect/Harbor runner, task package loader, scoring pipeline or report
  signer yet.
- The Python validator is an optional design gate, not a runtime dependency.
