## What this proves

- The current host is mapped to `linux` / `macos` / `windows` / `other` without
  a domain `cfg(target_os)` branch.
- Linux reports verified `runtime_home` and `secure_file`, degraded PTY,
  browser read-only, daemon, notifications and signing, and unsupported
  computer-use.
- macOS, Windows and other targets report every capability as `untested`; the
  tests fail if any of them claims `verified`.
- The report round-trips through JSON; `1agent platform --json` and the human
  output both expose the capability list.

## What this does not prove

- That 1Agent runs on Windows or macOS. No real host or VM was exercised.
- That the degraded Linux adapters are production-ready; the notes state their
  limitations.
- P-Gate. This is the registry and the gate's checklist, not a passed gate.
