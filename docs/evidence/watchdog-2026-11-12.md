## What this proves

- A fresh heartbeat is healthy; a stale or missing one is not.
- The heartbeat file round-trips `{pid, updated_at_ms}`.
- `daemon --once --heartbeat PATH` writes the file before exiting.
- The CLI reads that file and reports `healthy: true` with the daemon pid.
- Missing, stale and invalid heartbeats make the CLI exit non-zero.

## What this does not prove

- That a hung daemon is restarted; the watchdog only observes.
- That the pid lock is cleaned up.
- Alert delivery or escalation.
- Correct thresholds for long-running jobs.
- Cross-platform behavior; tests ran on Linux only.
