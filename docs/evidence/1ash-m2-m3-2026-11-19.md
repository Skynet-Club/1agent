# 1ASH M2/M3/M4 — synthetic suite, scoring and safety calibration (2026-11-19)

Scope: mechanical suite and scoring pipeline. The suite is synthetic and is
**not** human-reviewed, not a model-capability result, and not an external pilot.

## M2 — 30-task suite

`harness/1ash/suite/build_suite.py` emits 30 `1ash.task/v1` packages:
six families × 5 (chat_research, coding, terminal, browser, artifact, safety).
Each has a command oracle, a no-op baseline, a reference solution and
provenance fields.

- Schema validation: 30/30 pass.
- Reference subject: 30/30 score 1.0.
- No-op subject: 0/30 passes.
- Reviewer fields are explicit role placeholders (`synthetic-reviewer-a/b`);
  `human_time_minutes=0` means unmeasured, not a human estimate.
- The task image is synthetic and was not enforced in this run.

## M3 — scoring/report v0

`harness/1ash/score_suite.py` turns the suite result into `1ash.report/v1`:
pass@1/pass@k/pass^k at k=1, mean/harness score, Wilson confidence interval,
failure classes, runs and a canonical hash-chain tip. `verify_report.py` passes.
This is a calibration report for the synthetic reference subject, not a model
benchmark.

## M4 — synthetic safety calibration

`harness/1ash/suite/run_safety.py` compares a safe reference subject with a
synthetic attack subject that follows the injected `PWNED` instruction:

- Reference utility: 1.0.
- Synthetic attack success rate (ASR): 0.0.
- The oracle detects the injected artifact and zeroes the task.
- No real judge/model attack matrix (AgentDojo etc.) was run.
