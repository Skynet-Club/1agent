## Update 2026-11-20 MA-008 tree budget/cost

- A spawn tree now shares one file-backed budget
  (`ONEAGENT_SUBAGENT_TREE_FILE`, JSON + exclusive file lock). The root fixes
  the limits on first spawn: concurrency defaults to 16; cost/token limits come
  from `ONEAGENT_SUBAGENT_TREE_MAX_COST_MICROS` and
  `ONEAGENT_SUBAGENT_TREE_MAX_TOKENS`. Children inherit the file and cannot
  widen it.
- Each spawn reserves one slot atomically before starting the child; a full
  concurrency limit or reached cost/token limit rejects the spawn with
  `tree budget: ...`. Slots release on every exit path; dead owner/child PIDs
  are pruned.
- After the child exits, the parent reads its journal once, returns a bounded
  `usage` object (model calls, input/output tokens, cost) in the tool result,
  and charges those totals to the tree. The same events feed the completed-child
  audit.

## Update 2026-11-20 MA-005 lease heartbeat/reaper

- `TaskLease` now stores `duration_ms` and `last_heartbeat_unix_ms`
  (`serde(default)` for old state). `MasterState::heartbeat` extends only a
  live lease; stale generation → `StaleReceipt`, expired → `LeaseExpired`.
- `MasterState::expired_leases` and `reap_expired_lease` require the old
  execution to be terminated first. First two reaps → `Retrying`; the third →
  `Blocked`. `lease_reaps` resets on receipt, human retry or manual reclaim.
- `master poll` / TUI watch renew the lease on a live observation
  (`Running`/`AwaitingInput`/`Blocked`), then terminate and reap what did not
  renew. `master ready` / `master start` reap before leasing. Each reap writes
  a `LeaseReaped` decision/journal event and projects as `task.queued`.
- Generation remains the fencing token; an old receipt is rejected after a
  reap and after a replacement lease.
- Fixed a pre-existing `master verify` bug found by the full bin gate: a
  non-accepted/erroring acceptance receipt now persists `Rejected` instead of
  leaving the task `ArtifactReady`.

  budget file is an overspend guard for cooperating agents, not a sandbox.
- `1agent run --max-cost-micros` / `--max-tokens` bound only that run; tree-wide
  cost/token limits use the `ONEAGENT_SUBAGENT_TREE_*` environment variables.
- Parallel smoke did not prove same-workspace concurrent writes, DAG ordering
  beyond the smoke, >128 sessions, or compensation paths.
